# Pan American

Статичний сайт Pan American: підбір і доставка автомобілів зі США та Канади. Готовий сайт — `index.html`, медіа та стилі — `assets/panamerican/`.

## Локальний запуск

Відкрийте `index.html` або запустіть `python -m http.server 4173 --bind 127.0.0.1` і перейдіть на `http://127.0.0.1:4173/`.

## Редагування та перевірка

HTML-шаблон: `docs/reference/page-template.html`. Після редагування шаблону виконайте:

```text
python checks/build-rebrand.py
node checks/static.cjs
node checks/domain.test.cjs
```

Стилі: `assets/panamerican/site.css`, `redesign.css`, `mobile-fixes.css`. Поведінка: `site.js`. Калькулятор: `calculator.cjs`, з якого збірка копіює браузерний `calculator.js`.

Для повторної збірки потрібні `docs/reference/` та `backups/kent-cars-before-rebrand.html`: з резервного HTML береться географічний SVG карти. Для хостингу достатньо `index.html` та `assets/`.

## Поточна поведінка

- Сайт запускається з увімкненими анімаціями; маленький перемикач дозволяє їх призупинити. Системне зменшення руху приглушує декоративні цикли.
- Автомобілі та відео гортаються горизонтально стрілками або жестом, без перехоплення коліщатка миші.
- На телефоні маршрут закріплюється, етапи змінюються скролом. Лінія, транспорт і прогрес використовують одну часову шкалу.
- Текстові стрілки замінені SVG, щоб iOS не показувала емодзі. Фон має обмежену прозорість, меню соцмереж прив’язане до своєї кнопки.
- Контакти відокремлені від форми заявки. Форма готує текст звернення для пошти або копіювання; серверної відправки немає.
